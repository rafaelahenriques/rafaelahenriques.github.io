## Write messy first, clean later
The goal is understanding, not perfection.

## One feature at a time
Don’t jump between files. Finish one tiny thing.

## Learn by breaking
When something crashes, that’s the learning moment.

## Read errors
The error message is not an insult. It tells you what to fix.

## Repeat this
Understanding > memorizing.
